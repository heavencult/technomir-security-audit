## О проекте

Комплексный аудит веб-приложения интернет-магазина «ТехноМир» на базе
тестового стенда **OWASP Juice Shop**: поиск и анализ уязвимостей,
нагрузочное тестирование, расследование DoS-атаки и аудит сайта на
соответствие требованиям законодательства.
